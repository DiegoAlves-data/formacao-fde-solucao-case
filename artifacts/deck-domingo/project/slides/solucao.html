Arquitetura de solução ·
4 minutos. A solução de ponta a ponta. As fontes, por enquanto, são a base do kit, que simula os sistemas da Já Chegou. Cada sistema tem o seu conector: SEFAZ, ERP, WMS e banco. Trocar o mock pela fonte real muda só o conector. A API e a esteira rodam num Worker em TypeScript, com Cron. É ali que ficam os contextos do domínio. O Worker chama o Claude pelo SDK, com saída estruturada, e o Clef pelo Workers AI. A tela de aprovação fica atrás do Cloudflare Access: a pessoa entra com o e-mail. Os dados ficam no Supabase, em São Paulo, porque o cliente exige dado fiscal no Brasil. O aviso sai pelo Resend, e o GitHub Actions publica os Workers e aplica as migrações. A regra principal: só o Worker fala com o banco. O navegador nunca fala com o Supabase, e o servidor MCP chama a API, nunca o banco.
