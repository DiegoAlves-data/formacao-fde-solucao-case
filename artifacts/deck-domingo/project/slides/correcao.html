“Nunca eu quero uma branch com um nome Claude alguma coisa.”

Virou o hook branch-name-gate: uma branch com esse nome não é criada.

5 minutos. Na prática, engenharia de prompt não é escrever o prompt perfeito. É perceber que você está corrigindo a mesma coisa de novo e tirar essa correção do prompt. Primeiro eu corrijo na conversa. Se se repete, vira memória: hoje são 290 correções guardadas. Se vale sempre, vai para o CLAUDE.md ou vira skill. Se dá para checar com um script, vira hook. Exemplo: pedi para nunca criar branch com nome do Claude. Isso virou o hook branch-name-gate. No Ahrena, 35 das 91 regras são checadas por hook. As outras dependem de julgamento e ficam escritas.
